# Program 1

### What is the problem with the program
### If the player chooses an odd number of rows and an odd number of columns, the game will crash since it can’t make a matching set of tiles. 

### What solution did you implement?

### I told the program to check to see if the tile number is odd and if its odd to make a square nonplayable and says free square. This lets the tiles all have matching sets and not crash the program. 

### Does your solution have any drawbacks or limitations? Explain why or why not.

### The only drawback is you have a non-useable square on the board.
